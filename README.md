# Kahve Dükkanı E-Ticaret ve Sanal POS Sistemi

Harici hiçbir kütüphane kullanılmadan saf (Vanilla) HTML5, CSS3, ES6+ JavaScript ve Node.js çekirdek modülleriyle geliştirilmiştir.

## Yerel Çalıştırma
1. Terminalde klasörün içine girin.
2. `node server.js` komutunu çalıştırın.
3. Tarayıcıdan `http://localhost:3000` adresini açın.

## Varsayılan Yönetici Bilgileri
- **Kullanıcı Adı:** `kerim`
- **Şifre:** `kerim`
*(İlk girişten sonra Dükkan Yönetimi panelinden şifrenizi ve dükkan bilgilerinizi güncelleyebilirsiniz.)*

## Render.com Kurulumu
- **Start Command:** `node server.js`
- **Canlı Satış İçin Kalıcı Disk:** Render panelinden Disks sekmesine girip `/var/data` yolunu bağlayın ve Environment Variables kısmına `DISK_YOLU=/var/data` ekleyin.
